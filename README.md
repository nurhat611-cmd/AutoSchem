# AutoSchem

Клиентский мод Fabric для Minecraft Java Edition 1.21.11. Требуются Java 21, Fabric Loader 0.18.4 или новее и Fabric API для 1.21.11.

## Использование

1. Установите мод и Fabric API в папку `mods` клиента и запустите игру.
2. Поместите Sponge `.schem` в `config/autoschem/schemes`. Папки создаются автоматически. Поддерживаются схемы Sponge v1/v2 с `Palette` и `BlockData` и v3 с `Blocks.Palette` и `Blocks.Data`.
3. Дождитесь сообщения о подсчёте блоков. Готовый файл появится в `config/autoschem/vsch/`. Схемы, уже находящиеся в папке при запуске игры, также обрабатываются.
4. Откройте одиночный мир с мирной сложностью, наведите прицел на сторону блока и выполните `/autoschem start`. Схема начинается в соседнем с выбранной стороной блоке. Если прицел ни на что не наведён, начало находится на уровне ног на два блока впереди игрока. Оси схемы не поворачиваются.
5. `/autoschem stop` останавливает выполнение и сбрасывает прогресс. Уже изменённые блоки не восстанавливаются. При повторном запуске схема выполняется с начала.

Мод не строит на серверах и в мирах, открытых для LAN: команды и выполнение проверяют наличие одиночной игры. Локальная обработка файлов доступна даже в меню; сообщения о её результате появятся при входе в одиночный мир. Отключение, открытие мира для LAN, смена измерения или сложности останавливают строительство. Размер схемы ограничен двумя миллионами блоков, распакованные NBT-данные — 64 МиБ, палитра — 65 536 состояниями. Автоматического преобразования состояний из старых версий Minecraft нет.

**Перед строительством сохраните копию мира.** Мод изменяет блоки непосредственно во встроенном сервере одиночной игры, а не управляет игроком: он может заменить существующие блоки и содержимое контейнеров. Воздух схемы удаляет блоки, `structure_void` пропускается. Предметы из инвентаря не расходуются, а список ресурсов показывает количество блоков по их идентификаторам, а не точный рецепт предметов. Данные блок-сущностей, сущности, биомы и `Offset` из `.schem` не переносятся. Физика и соседние обновления Minecraft могут изменить некоторые состояния после установки.

При ошибке сведения с датой, координатами и стектрейсом добавляются в `config/autoschem/crash_report.txt`.

## Формат VSCH

Все числа записаны в порядке байтов Java `DataOutputStream` (big-endian). Сначала идут четыре несжатых байта `56 53 43 48` (`VSCH`). Остальная часть файла — один поток GZIP: `int` количества инструкций, затем для каждой инструкции `writeUTF(action)`, `int x`, `int y`, `int z`, `writeUTF(block_state)`, `int delay`. Действия — `PLACE` и `BREAK`, задержка измеряется в игровых тиках. Координаты относительны выбранному началу схемы.

## Сборка

Установите JDK 21 и выполните `./gradlew build` (Windows: `gradlew.bat build`). Мод будет создан в `build/libs/`; файл с суффиксом `-sources` не требуется для установки. GitHub Actions выполняет сборку и тесты и загружает обычный JAR как артефакт.
